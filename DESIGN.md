# Shortlist

Shortlist helps a small team choose a supplier without losing the context behind the decision. The main screen is a buying workspace, with constraints, supplier comparison, source evidence and a contextual agent.

Use a warm white background, deep green primary actions, dark readable text and restrained amber for unresolved facts. Keep the chosen offer prominent; show rejected offers with precise reasons. A comparison table belongs beside the source document, with an accessible stacked layout on narrow screens.

Manual corrections use a visible lock and a reason. Source excerpts remain selectable text. Recommendation changes show the previous and current supplier with undo. AI controls hand off to the framework agent sidebar. Standard controls use the toolkit adapter; the domain layout uses local CSS tokens.

No decorative illustrations are needed. The data, its source and the decision are the visual content.
